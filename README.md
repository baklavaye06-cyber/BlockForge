# BLOCKFORGE

A classic block puzzle game playable directly in your browser.

Play BLOCKFORGE online:

https://baklavaye06-cyber.github.io/BlockForge/

## Features
- Classic block puzzle gameplay
- Endless, Adventure and Daily Puzzle modes
- Responsive interface
- Free and open source
